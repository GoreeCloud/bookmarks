# Glaze adoption contract — development

Current GoreeCloud design authority: [Glaze V1.7 / 1.7.0](https://github.com/GoreeCloud/glaze), Stable/Anchor. V1.7.1 is Development and must not be presented as accepted. The official Stable module is `js/glaze-v1.7.0.mjs` and inherits the bounded accepted V1.6 runtime.

The initial source change establishes a **local, declarative, Glaze-directed presentation adapter** for the imported Next.js UI: semantic surfaces, visual rhythm, foreground contrast, keyboard-visible focus, reduced-motion behavior, product navigation, and theme support. It is not yet a direct qualified integration of the official Glaze runtime, not a migration of all pages, and not accepted consumer evidence.

## Completion criteria
- Vendor/pin the exact approved Glaze runtime or a maintained official distribution with auditable source, integrity and update path; verify compatible presentation-only behavior.
- Map every screen, state, icon, motion and interaction to the accepted contract; use native UI components in native clients.
- Ensure accessibility precedence and reduced-motion treatment; no authorization or navigation decisions derived from design state.
- Validate light/dark, mobile/tablet/desktop, loading, empty, error, offline, first-run and returning-user experiences.
- Complete repository-local Glaze acceptance for the exact source revision before describing this consumer as conformant.
